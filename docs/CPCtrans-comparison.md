# CPCtrans 舊版與 fuelcore 差異

比對來源是使用者指定的 H 槽封裝成品。檢查了舊版執行檔的封裝模組索引、檔案清單與 Rpx 編輯器介面，並核對 fuelcore 的程式入口與測試。舊版執行檔未啟動。模組索引能確認舊版包含哪些元件，實際行為與輸出仍需用相同測試資料核對。

| 項目 | fuelcore 目前範圍 |
| --- | --- |
| TXT、船舶清單、買方代碼 | 有轉檔前編輯、油品試算、船舶清單、歸檔與測試庫轉入。TPNet 查詢由使用者手動啟動。 |
| F6 邏輯檢查 | 使用另外部署的本機外掛。ZIP 不含舊版運算式引擎或 MySQL 相容模組。 |
| 送出、收信與正式庫 | 提供唯讀送信模擬、測試回覆匯入及監看。實際傳輸、正式庫及收信後歸檔仍是保留項目。 |
| Rpx 與列印 | 工作台有預覽、基本欄位修改、數量試算、更正 Excel 和 GDI 送印。舊版 HTML 的瀏覽器操作、版面範本與進階編輯未移植。 |
| 診斷與舊版工具 | 有本機安裝檢查及舊 Rpx 與測試庫欄位比對。舊版的通用規則設定、XML 設定匯出與排錯工具不在移植範圍。 |

上機後開啟「工具 → 診斷（可比對舊版 Rpx）」。若要看資料差異，先在測試庫轉入同一筆測試 TXT，再選舊版產出的 Rpx。只比較可對應到單一測試庫欄位的值。畫面顯示欄位值，「複製可分享摘要」只包含檢查狀態與差異欄位名稱。診斷不啟動舊程式、不執行 F6、不送印。
